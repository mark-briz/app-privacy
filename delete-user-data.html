Delete your Life Metric data

Request permanent deletion of the cloud account tied to your login email.

How this works

  1. Enter the email address you use to sign in to Life Metric.
  2. Select Send confirmation email.
  3. If that email belongs to an account, we send a confirmation link to it.
  4. Open the link within 5 minutes. After that the token expires and you must submit this form again.

Deletion is permanent: workouts, weight and blood-pressure readings, plans, profile, and the sign-in account are removed from our servers. If you are still signed in on a phone, use Profile → Delete account instead — that also clears data stored on the device.

Use the same email you sign in with. We never ask for your password on this page.

Operator setup (do not publish secrets)

Replace SUPABASE_URL and SUPABASE_ANON_KEY in the script below with your project values (the anon key already ships in the app — never put the service-role key in this file). Then:

  1. Run supabase/migrations/013_account_deletion_request.sql, 014_delete_account_auth_admin.sql, and 016_account_deletion_by_email.sql in the SQL Editor.
  2. Deploy Edge Functions request-account-deletion and confirm-account-deletion (verify_jwt = false on confirm so the email link works).
  3. Set function secrets RESEND_API_KEY and DELETION_FROM_EMAIL (for example Life Metric <noreply@your-domain>).
  4. Host this HTML over HTTPS (GitHub Pages or your site). Opening it as a local file:// page may be blocked by the browser.
